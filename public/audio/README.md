# Demo Audio Files

Plasser dine WAV-filer her med disse filnavnene:

- `neon-skyline.wav`
- `midnight-runner.wav` 
- `digital-rain.wav`
- `chrome-horizon.wav`
- `electric-dreams.wav`
- `cyber-pulse.wav`

Eller rediger `data/tracks.ts` for å matche dine filnavn.

## Støttede formater:
- **WAV** (anbefalt for beste kvalitet)
- **MP3** (god kompatibilitet)
- **OGG** (god kvalitet, mindre filer)

## Tips:
- WAV-filer gir best lydkvalitet men er større
- Plasser filene direkte i denne mappen
- Filnavnene må matche `audioUrl` i tracks.ts

Lydfilene lastes automatisk når brukere klikker på låtene i listen eller bruker platespiller-kontrollene.
